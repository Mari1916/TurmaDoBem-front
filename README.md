# 💚 TDB Conecta

### Plataforma digital centralizada da Turma do Bem

O **TDB Conecta** é uma plataforma digital desenvolvida para centralizar e facilitar a relação entre a **Turma do Bem**, seus doadores, voluntários, empresas parceiras e pessoas que buscam apoio.

A proposta é reunir diferentes jornadas em um único ambiente, permitindo que cada usuário tenha acesso às funcionalidades correspondentes ao seu perfil, enquanto a organização possui uma visão centralizada das informações, projetos, campanhas, doações e oportunidades de relacionamento.

---

## 🎯 Sobre o Projeto

O TDB Conecta foi desenvolvido com o objetivo de criar uma experiência digital mais organizada, acessível e integrada para os diferentes públicos da organização.

A plataforma reúne funcionalidades como:

* 💰 Doações para pessoas físicas;
* 🏢 Cadastro e relacionamento com empresas;
* 🤝 Inscrição e participação de voluntários;
* 🫶 Solicitação e acompanhamento de apoio;
* 📊 Transparência e acompanhamento de impacto;
* 📋 Campanhas e projetos;
* 🎫 Passaporte do Bem;
* 🤖 Assistente virtual;
* 📈 Área administrativa para gerenciamento das informações.

---

## 💡 Solução

A plataforma funciona a partir de um **ecossistema único**, no qual diferentes perfis possuem jornadas específicas.

### 👤 Pessoa Física

O usuário pode realizar uma doação pontual sem necessariamente criar uma conta.

Após a doação, também pode optar por criar um perfil e manter um relacionamento com a organização, tendo acesso a recursos como:

* Histórico de doações;
* Passaporte do Bem;
* Campanhas;
* Impacto das contribuições;
* Certificados e reconhecimentos;
* Indicador de relacionamento/engajamento;
* Preferências de comunicação.

### 🏢 Empresa

Empresas devem realizar seu cadastro e estabelecer seu vínculo com a organização antes de efetuar doações.

A área empresarial permite acompanhar:

* Histórico de doações e apoios;
* Projetos apoiados;
* Status da parceria;
* Certificados e reconhecimentos;
* Relatórios de impacto.

### 🤝 Voluntário

O voluntário pode:

* Criar seu cadastro;
* Informar interesses e disponibilidade;
* Consultar oportunidades;
* Participar de atividades;
* Acompanhar seu histórico de participação.

### 🫶 Pessoa que busca apoio

O usuário pode:

* Realizar seu cadastro;
* Escolher o programa ou tipo de apoio;
* Enviar as informações necessárias;
* Acompanhar o status da solicitação;
* Receber atualizações sobre o atendimento.

### 🔐 Administrador

A área administrativa centraliza informações e permite acompanhar:

* Usuários;
* Doadores;
* Empresas;
* Voluntários;
* Beneficiários;
* Campanhas;
* Projetos;
* Doações;
* Solicitações de apoio;
* Indicadores;
* Relatórios;
* Oportunidades de relacionamento;
* Registros de ações administrativas.

---

## 🤖 Assistente Virtual

O TDB Conecta também prevê um **assistente virtual**, desenvolvido com **Watsonx Assistant**, para auxiliar os usuários durante sua navegação.

O chatbot poderá ajudar em situações como:

* Dúvidas sobre a organização;
* Orientação sobre doações;
* Informações sobre voluntariado;
* Orientação para solicitação de apoio;
* Navegação pela plataforma;
* Direcionamento para funcionalidades específicas.

A solução também prevê integração com **Telegram por meio do Node-RED**, além de suporte para interação por texto e áudio.

## 🚀 Como Executar o Projeto

Como o Sprint 01 utiliza HTML e CSS, não é necessário instalar dependências.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd TDB-Conecta
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

em um navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para facilitar o desenvolvimento.
